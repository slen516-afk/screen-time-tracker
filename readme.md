# ScreenTime PC - 螢幕使用時間與數位分身反饋系統

這是一款專為 Windows 系統設計的 **iOS 風格螢幕使用時間（Screen Time）** 追蹤與管理系統。結合了 **精準活躍視窗監控**、**智慧閒置判定**、**動態網頁分類**、**高強度強制鎖定阻擋**、**可拖曳桌面浮動小工具**，以及極富養成樂趣的 **數位分身（Virtual Pet）反饋系統**。

---

## 🌟 核心特色功能

### 1. 精準活躍視窗追蹤與智慧閒置
* 透過 Windows 原生 API (`ctypes`) 即時捕捉目前聚焦的活動視窗與處理序名稱。
* **智慧閒置判定 (Idle Detection)**：系統會監測滑鼠與鍵盤的實際物理輸入。若無動作超過設定時間（預設 60 秒），系統將會自動暫停計時，確保您的數據真實精準，不受暫離電腦影響。

### 2. 動態類別分類 (Education vs Entertainment)
* 系統除了對常見軟體（如 VS Code、Notepad、Discord）進行靜態分類外，還內建了 **即時標題分析器**。
* 當您使用 Chrome、Edge 或 Firefox 等瀏覽器時，分析器會依據網頁分頁標題的關鍵字，動態將當前瀏覽器會話分類為 **「教育學習 (Education)」**（以霓虹青顯示，包含 Wikipedia、Coursera、學校課程網站、程式學習等關鍵字）或 **「影音娛樂 (Entertainment & Media)」**（以霓虹紅顯示，包含 Netflix、Youtube、Twitch、Steam 等關鍵字）。
* 本機 WSL 終端機 (`wsl.exe`) 與各大 IDE 自動歸類為教育學習。

### 3. iOS 磨砂玻璃質感儀表板
* **即時數據更新**：儀表板每 3 秒自動更新一次，呈現最即時的活躍應用程式狀態。
* **精美 Chart.js 圖表**：iOS 風格的柱狀圖清晰展示 24 小時內每小時的使用分佈。
* **最常使用排行**：顯示今日各應用程式的使用總時間與百分比進度條，並可點擊展開查看具體的視窗標題細節。
* **活動時間線**：依照時間順序記錄今日所有操作的詳細歷程，幫助您追蹤時間的流向。

### 4. 桌面毛玻璃浮動小工具 (Desktop Widget)
* 一鍵開啟無邊框、半透明的桌面浮動小卡。
* **功能操作**：
  * **滑鼠左鍵拖曳**：可自由移動小工具至桌面任意位置。
  * **滑鼠右鍵選單**：切換 **📌 置頂釘選**（Always on Top）、調整 **半透明度**（30% ~ 100%）、一鍵開啟 Dashboard 或關閉小工具。
  * **滑鼠左鍵雙擊**：快速開啟 Web Dashboard。

### 5. 高強度鎖定阻擋機制 (Anti-Bypass Lockout)
* 在儀表板為特定程式或整個應用類別（例如限制影音娛樂類別每日 1 小時）設定限額。
* **主動式防繞過鎖定**：一旦使用時數超額：
  1. 系統自動發出 Windows 桌面通知。
  2. 超額程式視窗將立刻被自動最小化。
  3. 彈出置頂且無邊框的 **「時間限制已達」** 磨砂玻璃卡片。
  4. 若您在鎖定狀態下試圖在 Windows 工作列點擊還原被鎖定的程式，追蹤引擎會**在 1 秒內偵測並再次將其強制縮小**，實現真正「鎖起來」的效果。
* **彈性解除選項**：
  * **確定 (關閉)**：繼續維持該程式最小化鎖定狀態。
  * **再使用 1 分鐘**：給予 60 秒的緊急緩衝時間（例如讓您存檔），時間到後會再次強制鎖定。
  * **今日忽略限制**：今日完全放行，不再阻擋。

### 6. 數位分身反饋系統 (Virtual Pet Gamification)
* 統計您過去 30 天的「教育學習」與「影音娛樂」總時數，賦予數位分身動態的反饋進化：
  * **等級 1：初階數碼蛋 (0 - 5 小時)** - 剛出生的初階數位分身，充滿對新事物的渴望，需要多讀書或寫程式來進化。
  * **等級 2：自學機器人 (5 - 20 小時)** - 開始吸收大量基礎知識，手臂裝備了初階編譯器，眼神中透露著智慧的光芒。
  * **等級 3：數據編譯大法師 (20 - 50 小時)** - 能夠流暢編寫各類程式，操縱多維度虛擬程式面板，對演算法的理解達到爐火純青。
  * **等級 4：星際科技賢者 (50 - 100 小時)** - 大腦已與量子雲端進行神經連結，能隨意編織代碼，通曉數據演變的大道法則。
  * **等級 5：終極數位真神 (100+ 小時)** - 超越肉體凡胎，化身為掌控網絡底層架構的至高數位真神。
* **疲勞與萎靡機制**：若 30 天內娛樂時間 > 30 小時，或是娛樂時間大於學習時間的 1.5 倍，角色會立刻進入 **「沙發土豆 (萎靡狀態)」**。分身會癱在沙發上吃洋芋片看劇，雙眼失神、數據嚴重溢出。您必須透過教育學習來喚醒他！

## 🚀 快速啟動指南

### 環境準備
本專案專為 **Windows** 作業系統設計，您只需要安裝 Python 3.8 或以上版本。

### 啟動步驟
1. 開啟本專案資料夾 `c:\Users\User\Desktop\screentime for pc`。
2. 雙擊執行 **`run.bat`**。
3. 批次檔會自動執行：
   * 檢查並自動安裝 missing 依賴項（`Flask`, `psutil`, `plyer` 等）。
   * 後台自動啟動追蹤引擎 `tracker.py`。
   * 啟動 Flask 伺服器並**自動開啟您的預設瀏覽器**導向網頁儀表板 `http://127.0.0.1:5000`。
4. 如需停止，只需關閉 `run.bat` 彈出的黑色命令列視窗即可。

## 📊 資料庫架構說明

本系統使用無伺服器、輕量化的 SQLite 資料庫進行本地持久化：
* **`window_logs`**：記錄使用者的視窗焦點歷史。欄位包含 `app_name` (執行檔名)、`window_title` (視窗標題)、`start_time` / `end_time` (時區修正的 ISO 本地時間)、`duration` (持續秒數) 以及動態分類出來的 `category`。
* **`app_categories`**：儲存應用程式的自訂顯示名稱與預設分類。
* **`daily_limits`**：儲存每日的使用限制額度。
* **`settings`**：儲存核心設定項目（例如閒置時間判定閾值）。
